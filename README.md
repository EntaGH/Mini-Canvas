# Console Drawing Program

A simple console-based drawing program implemented in C#.

## Design Notes

### Dependency Injection

This solution **does not use Dependency Injection (DI)** as it's just a coding challenge

The application is intentionally kept simple because this is a small console application with limited dependencies and a straightforward execution flow.

Dependencies such as `Canvas` and `CommandHandler` are instantiated directly where needed rather than being registered in a DI container.
